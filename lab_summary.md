The hardest part was defining a useful autonomous workflow without removing the human control that the sales process still needs. I also had to decide carefully which steps should use an LLM and which should rely on deterministic rules, because that balance affects trust and clarity. If I repeated the planning process, I would define the evaluation test cases and data schema much earlier. The biggest open question is how reliably the agent could handle incomplete, messy, or multilingual real customer inquiries while property availability changes very frequently.
